# בדיקת טלפון לפני v0.2.0

רשימה לבדיקה בטלפון, בערך 10–15 דקות. כל שורה: **מה עושים** ← **מה אמור לקרות**.
סמן ✅ או ❌ ליד כל שורה. אם משהו ❌, כתוב במילה אחת מה ראית (וצילום מסך אם אפשר).

כתובת המשחק: https://sagi0011-svg.github.io/slide-rush/

**חשוב — את סעיף 1 עושים ראשון**, לפני שלוחצים על משהו אחר. הוא בודק שהשמירה הישנה מ-v0.1 עברה בשלום, ואפשר לבדוק את זה רק פעם אחת.

## 1. שמירה ישנה (רק אם שיחקת בגרסה הקודמת בטלפון הזה)

- [ ] פותחים את המשחק ← במסך הפתיחה מופיע **BEST** עם השיא הישן שלך (לא 0).
- [ ] למעלה מימין מופיעה יתרת מטבעות ← היא **לא 0** אם אספת מטבעות בגרסה הקודמת.
- [ ] באמצע המסך יושבת **צפרדע בתוך גלגל ים כחול-לבן** ומתנדנדת.
- [ ] לוחצים **Play** ← **לא** מופיעה שוב ההדרכה (החיצים "Swipe…"), כי כבר ראית אותה.

## 2. שליטה ומכשולים

- [ ] החלקה ימינה/שמאלה ← עוברים מסלול מיד, בלי עיכוב מורגש.
- [ ] החלקה למעלה ← קפיצה. החלקה למטה ← התכופפות לתוך הגלגל.
- [ ] החלקה למטה **באמצע קפיצה** ← נוחתים מהר.
- [ ] **מוקש אדום עם קוצים** (נמוך) ← קופצים מעליו או עוברים מסלול. פגיעה = סוף משחק.
- [ ] **קשת/מוט כחול** (גבוה) ← מתכופפים מתחתיו או עוברים מסלול. פגיעה = סוף משחק.
- [ ] **ארגזים/שער** (חוסם מסלול שלם) ← רק מעבר מסלול עובר. פגיעה מקדימה = סוף משחק.
- [ ] **מתנפח צהוב** (נמוך) ← פגיעה בו = רק מעידה: המסך רועד, האטה קצרה, המשחק ממשיך.
- [ ] שתי מעידות תוך כמה שניות ← סוף משחק.
- [ ] מעבר מסלול **לתוך הצד** של מכשול ← מעידה וקפיצה חזרה למסלול הקודם (לא מוות).

## 3. מטבעות ומכפיל

- [ ] נוגעים במטבע ← הוא נעלם, נשמע צליל, המספר של המטבעות למעלה עולה ב-1.
- [ ] משחקים 30 שניות בלי למעוד ← המכפיל למעלה עולה ל-**x2** (ואחרי עוד 30 שניות ל-x3).
- [ ] מועדים ← המכפיל חוזר ל-**x1**.

## 4. שלושת הכוחות המיוחדים

הם מופיעים בערך כל 15 שניות, כטבעת צפה עם סמל.

- [ ] **מגן** (בועה תכלת) ← פגיעה אחת במכשול לא הורגת; הבועה מתפוצצת, והמכפיל **לא** מתאפס.
- [ ] **מגנט** (סגול) ← מטבעות מכל שלושת המסלולים עפים אליך.
- [ ] **טורבו** (כתום) ← מהירות כפולה ל-5 שניות, עוברים דרך מכשולים בלי להיפגע, ומטבעות נאספים לבד.
- [ ] כשכוח פעיל ← למעלה מופיע פס שמתקצר עד שהוא נגמר.

## 5. השהיה וסוף משחק

- [ ] לוחצים על כפתור ההשהיה למעלה ← המשחק קופא, מופיעים Resume / Restart / Home.
- [ ] **Resume** ← ממשיכים בדיוק מאותה נקודה.
- [ ] באמצע ריצה עוברים לאפליקציה אחרת וחוזרים ← המשחק **מושהה** ומחכה לך (לא מת לבד).
- [ ] כפתורי **Sound** ו-**Shake & flash** במסך ההשהיה ← מדליקים/מכבים, וזה נשמר גם בריצה הבאה.
- [ ] מתים ← רגע קצר בהילוך איטי, ואז מסך **Game Over** עם: ניקוד, מטבעות שנאספו בריצה, **סה״כ מטבעות**, שיא.
- [ ] שוברים שיא ← מופיע **New best!**
- [ ] **Play Again** ← ריצה חדשה מתחילה מיד.

## 6. בדיקת מחירים (הכי חשוב לי ממך)

- [ ] רושמים את יתרת המטבעות במסך הפתיחה: ______
- [ ] משחקים **3 ריצות רגילות** — כמו שאתה משחק בדרך כלל, לא במיוחד טוב ולא במיוחד גרוע.
- [ ] אחרי כל ריצה רושמים מסך Game Over: מטבעות בריצה ______ / ______ / ______
- [ ] בסוף: האם יכולת לקנות משהו (הכי זול: **Hula Hoop ב-300**)? כן / לא
- [ ] במשפט אחד: המחירים מרגישים זולים מדי / בסדר / יקרים מדי?

## 7. החנות

- [ ] במסך הפתיחה לוחצים **Shop** ← נפתחת חנות עם שתי לשוניות: **Animals** ו-**Rings**.
- [ ] לוחצים על פריט שאין לך ← רואים תצוגה גדולה שלו **ביחד** עם מה שכבר לבשת (למשל צפרדע בתוך פיצה).
- [ ] פריט יקר מדי ← כתוב על הכפתור **Need ___ more** (כמה חסר), הוא חיוור ואי אפשר ללחוץ עליו.
- [ ] פריט שיש לך מספיק בשבילו ← **Buy** ← מופיעה שאלה "Buy … for …?" ← **Not yet** ← שום דבר לא נקנה, המטבעות לא ירדו.
- [ ] שוב **Buy** ← **Yes, buy it** ← צליל קנייה, מטבעות קופצים, היתרה יורדת במחיר המדויק, והפריט **נלבש מיד**.
- [ ] בכרטיס של הפריט שקנית כתוב **Equipped**; על פריט ישן שיש לך כתוב **Owned**.
- [ ] לוחצים על פריט שיש לך ← **Wear it** ← מחליף, בלי לשלם שוב.
- [ ] **מחווה "אחורה" של הטלפון** (החלקה מהצד / כפתור אחורה באנדרואיד) כשאתה בחנות ← חוזרים למסך הפתיחה, **לא** יוצאים מהמשחק.
- [ ] כפתור **Back** בחנות ← אותו דבר.
- [ ] מתחילים ריצה ← הדמות על המגלשה היא מה שקנית.
- [ ] גם במסך Game Over יש כפתור **Shop** ← הוא פותח את החנות.

## 8. הקנייה נשמרת

- [ ] סוגרים את הדפדפן **לגמרי** (מחליקים אותו החוצה מרשימת האפליקציות הפתוחות) ופותחים מחדש את הכתובת.
- [ ] במסך הפתיחה ← הדמות היא עדיין מה שקנית, היתרה זהה למה שהייתה לפני הסגירה.
- [ ] בחנות ← מה שקנית עדיין מסומן **Owned** / **Equipped**.

## 9. מראה וחלקות

- [ ] המשחק נראה פיקסלי ומכוון (ריבועים חדים), עם שמיים של שקיעה וגבעות סגולות מאחור.
- [ ] בצדדים של המגלשה יש **דשא ירוק**, ועליו עומדים מגדלים, עצים, דקלים ובקתות. בקצה הרחוק הדשא נמוג לאט לתוך השקיעה, בלי קו חד.
- [ ] שום כפתור או מספר לא מוסתר מאחורי ה"חריץ" של המצלמה או בתחתית המסך.
- [ ] **חלקות:** במשך ריצה של דקה-שתיים התנועה רציפה, בלי קפיצות או גמגומים. (אם אתה רוצה מספר: פתח את הכתובת עם `?debug=1` בסוף, והשורה **fps** אמורה להיות קרוב ל-60.)
- [ ] באמצע ריצה מסובבים את הטלפון לרוחב ← כל המסך מתכסה בהודעה **Turn your phone upright to play**. מחזירים לאורך ← המשחק **מושהה** ומחכה ל-Resume. (צריך שנעילת הסיבוב בטלפון תהיה כבויה.)

## אם יש לך עוד 2 דקות

- [ ] בדיקה במחשב: חיצים / WASD / רווח עובדים, **Esc** בחנות מחזיר למסך הפתיחה.
- [ ] גלריית הדמויות: הכתובת עם `?debug=1&gallery=1` בסוף ← כל 66 הצירופים של חיה+גלגל ברורים.

## נספח: מה המספרים אומרים על המחירים

היעד במסמך התכנון: **הקנייה הראשונה אחרי בערך 3 ריצות רגילות**.

חישבתי את זה מהמשחק עצמו: תוכנה קטנה שיחקה 20 ריצות אמיתיות (אותה מגלשה, אותם מכשולים ומטבעות) ואספה כל מטבע שאפשר. כמה מטבעות **יש** על המגלשה, לפי אורך הריצה:

| אורך ריצה | מטבעות על המגלשה |
|---|---|
| 30 שניות | ~85 |
| דקה | ~195 |
| דקה וחצי | ~325 |
| 2 דקות | ~505 |

שחקן אמיתי לא אוסף הכול. לכן, הקנייה הראשונה (Hula Hoop, 300):

| שחקן | ריצה טיפוסית | מטבעות לריצה | ריצות עד 300 |
|---|---|---|---|
| מתחיל | ~30 שניות, אוסף שליש | ~30 | **~10** |
| רגיל | ~דקה, אוסף שני שלישים | ~130 | **3** |
| טוב | ~2 דקות, אוסף כמעט הכול | ~450 | **1** |

הנתון האמיתי היחיד שיש (כמה ריצות ראשונות, קצרות, בלי ניסיון: 97 מטבעות, שיא 2,167) מתאים לשורת ה"מתחיל". לקנות **הכול** עולה 24,500 מטבעות: בערך 190 ריצות רגילות, או 55 טובות.

**ההמלצה שלי: להשאיר את המחירים כמו שהם ל-v0.2.0.** לשחקן רגיל הם פוגעים בדיוק ביעד של 3 ריצות, והנתון היחיד שסותר את זה הוא מריצות ראשונות של מישהו שעוד לומד.

**מתי לשנות:** אם בבדיקת המחירים (סעיף 6) 3 הריצות שלך — או, עדיף, של מישהו שלא שיחק אף פעם — מביאות **פחות מ-250 מטבעות ביחד**, או שזה פשוט מרגיש איטי, יש חלופה מוכנה, "התחלה רכה": מורידים רק את 4 הזולים, וכל השאר נשאר:

| פריט | היום | התחלה רכה |
|---|---|---|
| Hula Hoop | 300 | 150 |
| Donut | 500 | 300 |
| Penguin | 500 | 350 |
| Pineapple Ring | 600 | 450 |

אז גם מתחיל קונה משהו אחרי בערך 5 ריצות, ושחקן רגיל אחרי 2. זה שינוי של 4 מספרים ב-`src/config.ts`, ועדכון מכוון של `tests/shop.spec.ts` (שנועל את טבלת המחירים).
